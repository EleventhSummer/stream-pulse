# Stream Pulse PRD

状态：已冻结。实现过程中发现的新想法记到「后续」一节，本周不开发。

## 1. 背景

运营同学需要一个极简看板，查看当前直播间是否在播、人气是否异常，并点进单个房间看趋势和最近评论。本项目用 mock 数据模拟该场景，用来走通前端交付流程。

## 2. 角色

仅一种角色：运营（登录后即可使用全部只读功能）。无权限分级。

## 3. 账号

| 用户名 | 密码 | 说明 |
|---|---|---|
| demo | demo123 | 唯一可用账号 |

错误密码返回 401，文案：「用户名或密码错误」。

## 4. 范围

### 4.1 In Scope

1. 登录 / 退出
2. 房间列表：关键词搜索、状态筛选、分页
3. 房间详情：关键指标、观众趋势图、最近评论
4. 直播中房间详情自动刷新（8 秒）
5. loading / empty / error / 404

### 4.2 Out of Scope

注册、验证码、权限、房间增删改、真弹幕、WebSocket、礼物、连麦、数据导出、移动端独立站、暗色主题切换（可用系统默认一套样式）。

## 5. 页面与验收

### 5.1 登录 `/login`

- 未登录访问其他业务路由，跳转到 `/login?redirect=<原路径>`
- 登录成功写入 token，跳转 `redirect` 或 `/rooms`
- 已登录访问 `/login`，直接去 `/rooms`

### 5.2 列表 `/rooms`

- 默认展示第 1 页，每页 6 条，共 12 个房间（2 页）
- 搜索框按房间标题或 ID 过滤（后端过滤，前端只传 `q`）
- 状态筛选项：全部 / 直播中 / 未开播 / 封禁，对应 `status=live|offline|banned`
- 进入、搜索、改筛选、翻页都要有 loading
- 结果为 0：EmptyState「没有符合条件的房间」
- 接口失败：ErrorState + 重试按钮

### 5.3 详情 `/rooms/:id`

- 展示标题、状态、封面占位、在线人数、点赞、开播时长（未开播显示 `-`）
- 折线图：最近 12 个采样点的在线人数
- 评论列表最多 10 条，按时间倒序
- `status=live` 时每 8 秒重新请求详情；离开页面必须停止
- 房间不存在：404 页，提供回列表链接

### 5.4 全局

- 顶栏：产品名、当前用户名、退出
- 退出后 token 消失，再访问 `/rooms` 回到登录

## 6. 非功能

- TypeScript 严格模式，不允许 `any` 扩散（第三方图表类型可用最小断言）
- 开发环境通过 Vite proxy 访问 mock，浏览器 Network 可见 `/api/*`
- 不在 Vue 组件里直接 `fetch` 业务 URL
- 轮询必须可清理，避免切页后继续请求
